PustakaDigital - Aplikasi Java Swing
====================================
Butuh JDK 11 atau lebih baru.

Cara 1 (terminal / CMD):
  javac PustakaDigitalApp.java
  java PustakaDigitalApp

Cara 2 (IDE: NetBeans / IntelliJ / VS Code):
  Buat project Java, masukkan file PustakaDigitalApp.java, lalu Run.

Catatan:
- Jendela bisa diperbesar (maximize); ukuran minimum 1200x700 sehingga tidak ada scroll.
- Data dibatasi maksimal 6 buku / 6 pengguna / 6 buku di rak agar selalu muat di layar.
